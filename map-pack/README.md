# Offline Map-Pack Handoff

No map binary is included in this public repository. `manifest.example.json` defines the minimum metadata a contractor should consume for a pinned, non-authoritative presentation pack.

The production provider, license, area-selection policy, retention, integrity verification, and update mechanism remain Floodcaster decisions. A contractor must not demonstrate offline caching with a provider license that forbids production offline use and imply that the result transfers.
